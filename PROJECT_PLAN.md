# Project Plan

## Problem

Certificates issued by educational institutions and training organisations may require verification to confirm their authenticity.

## Proposed Solution

This project will explore the use of the Algorand blockchain for creating a verifiable digital record associated with a certificate.

## Initial Development Stages

1. Learn how to connect an application to Algorand.
2. Create and test Algorand transactions.
3. Determine how certificate information can be represented digitally.
4. Record certificate-related information using Algorand.
5. Retrieve and verify the recorded information.
6. Develop a simple user interface for certificate verification.

## Current Stage

Project repository creation and initial planning.
