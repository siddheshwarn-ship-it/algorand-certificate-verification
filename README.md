# Algorand Certificate Verification

## Project Overview

This project aims to explore how the Algorand blockchain can be used to create a simple and transparent certificate verification system.

Educational institutions and training organisations issue many certificates. Verifying whether a certificate is genuine can sometimes be difficult. This project will explore the use of blockchain technology to create a digital record that can later be used to verify a certificate.

## Objectives

- Learn how to develop applications using the Algorand blockchain.
- Explore Algorand transactions and blockchain records.
- Create a simple method for registering certificate information.
- Allow certificate information to be verified using blockchain data.
- Gradually develop the project as new Algorand concepts are learned during the course.

## Planned Workflow

1. Create a certificate record.
2. Generate or store identifying information for the certificate.
3. Record relevant information using Algorand.
4. Retrieve the blockchain record.
5. Verify whether the certificate matches the recorded information.
